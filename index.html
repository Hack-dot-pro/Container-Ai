Thông Tin Hệ Thống

Luồng xử lý (giữ nguyên kiến trúc V11)
  1. Import Excel 6 cột → Master Data (localStorage: cp11_master)
  2. Chọn mã hàng → Lên target Hàng chờ (cp11_queue)
  3. Hàng nhỏ: mở Pallet Builder 3D gom thùng
  4. Chạy Load Tự Động → chia container <20 tấn, 32 kiện (cp11_conts)
  5. Kéo thả trong 3D (CTRL), xoay (R) → lưu slotId
  6. Xuất Packing List Excel từng container
Lưu ý: Dữ liệu lưu trên trình duyệt — hãy Xuất JSON để sao lưu định kỳ.
